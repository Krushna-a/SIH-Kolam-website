# Screenshots Directory

Add your application screenshots here with the following names:

## Required Screenshots

1. **homepage.png** - Landing page with featured Kolam designs
2. **products.png** - Product catalog with filter options
3. **generator.png** - AI Kolam generator interface
4. **cart.png** - Shopping cart and checkout page
5. **seller-dashboard.png** - Seller product management
6. **profile.png** - User profile and order history

## How to Add Screenshots

1. Run your application locally or use production site
2. Take screenshots using:
   - Windows: Win + Shift + S
   - Mac: Cmd + Shift + 4
   - Browser: F12 → Device toolbar for mobile view
3. Name files exactly as listed above
4. Place them in this folder
5. Screenshots will automatically appear in main README

## Image Guidelines

- **Format**: PNG or JPG
- **Resolution**: 1920x1080 (desktop) or 375x812 (mobile)
- **Size**: Keep under 500KB per image
- **Quality**: Clear, readable UI elements
- **Content**: Show key features in action
